# SecureVault Security Requirements

## Security Verification Target

SecureVault targets OWASP ASVS Level 2.

The application handles sensitive information such as
user credentials, documents, API keys, and other secrets.

Therefore, the project requires stronger security controls
than a basic application.

OWASP ASVS 5.0 is used as the primary security reference.

## Current Status

Target: ASVS Level 2
Verification: In Progress
